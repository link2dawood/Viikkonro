# Viikkonro

Viikkonro is a Finnish-language utility for checking ISO week numbers, browsing calendar views, exploring public holidays, and understanding date logic in Finland.

Built with React and Vite, the project is designed to be fast, practical, and easy to contribute to. It combines a user-friendly frontend with structured, SEO-aware pages and data exports that make it useful beyond simple calendar browsing.

## Why this project exists

This project makes common date and calendar questions easier to answer in Finnish:

- What is the current ISO week number?
- Which week is this date in?
- How do public holidays and working days work?
- Which dates are name days or holiday-related?
- How to browse calendar content by year, month, or quarter?

## Features

- ISO week number and date calculation
- Year, month, and quarter-based calendar views
- Holiday and working-day information
- Name-day and date-related content
- Finnish-language experience and content
- SEO-friendly static pages and AI-readable output
- Fast frontend built with Vite + React

## Getting started

### Prerequisites

- Node.js 22+
- npm

### Installation

```bash
git clone https://github.com/link2dawood/Viikkonro.git
cd Viikkonro
npm install
```

### Run locally

```bash
npm run dev
```

### Lint and test

```bash
npm run lint
npm test
```

### Production build

```bash
npm run build
```
