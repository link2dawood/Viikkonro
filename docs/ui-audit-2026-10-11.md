## Scope and completed checks

- Automated read-only Chromium inspection of **1,921 generated HTML routes**, each at **390px and 1280px**, totaling **3,842 route/viewport combinations**. Intentional redirect documents, the dedicated widget entry and 404 are handled separately. This is local production-build coverage, not 1,921 live-domain visits or manual visual reviews.
- The completed scan recorded no JavaScript page errors. Completed page loads had shared header/footer, one main landmark and one H1, and no duplicate IDs. One concurrent navigation timed out for `/tyopaivat-marraskuu-2023`; separate live checks at both widths passed.
- **55 live product-page checks**: 11 page types at 320, 390, 768, 1280 and 1440px. Shared chrome and body layout passed those checks. A separate control audit identified the Vacation Pro inconsistency above.
- Live HR and construction controls, project/sprint controls, company purchase availability, and actual HR/construction PDF, XLSX, ICS and construction CSV downloads were checked successfully.
- A synthetic authenticated account exercised login, private leave planning, private ICS, shift workspace, accounting workspace shell and logout. Temporary account/organization data was removed. No emails were sent, no JavaScript page errors occurred and browser authentication tokens were not persisted. This was an owner-path smoke test, not all-role or all-client CRUD coverage.
- Widget browser cases passed for isolated embedding, mobile/keyboard behavior, date boundaries, many events, injection resistance and message separation. An invalid live URL returned a real 404 with shared chrome and no mobile overflow.
- A focused 20-combination rerun validated the audit script's filtering of intentionally hidden controls and contained table scrolling. ESLint passed for the new script.

## Reviewed flags that are not defects

- Six template preview tables extend inside their own horizontal scroll wrappers. For example, the HR template at 390px has a 356px-wide wrapper containing a 1,078px table; the page itself remains 390px wide.
- The contact form's offscreen, aria-hidden honeypot is intentional.
- Buttons in closed disclosure panels have labels in their markup; empty `innerText` while hidden is not an unnamed visible control.
- Vacation Pro's product-specific “not yet on sale” message describes an unlaunched product. It does not mean Company Calendar payments are unavailable.
- The earlier HR/construction native-control issues, missing private-route header/footer and narrow vacation comparison section are corrected in the live pages checked here.

## Limitations and release recommendation

Do not describe this as a complete accessibility, cross-browser, security or payment certification. Safari/Firefox, assistive technology, field Core Web Vitals, every authenticated role/client operation, a real paid order, customer invoice inbox delivery and promotional consent lifecycle were not fully exercised in this audit. No customer purchase was made and no invoice was sent.

Fix the three confirmed issues, update the stale payment expectations, then run the relevant gates in [the deployment checklist](predeployment-test-cases.md). That checklist contains 125 explicit additional cases with expected results; it is a test plan, not a claim that every case passed today.

## Reproducing the read-only layout scan

Build the site and serve its production output on localhost:4173. Provide Playwright and Chromium if they are not installed in the project's environment:

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs \
CHROMIUM_PATH=/path/to/chrome \
UI_AUDIT_URL=http://localhost:4173 \
node scripts/ui-audit.browser.mjs
```

Use `UI_AUDIT_ROUTES=/lomasuunnittelija,/data/month` for a focused rerun and `UI_AUDIT_OUTPUT=/tmp/another-audit` to preserve previous results. The script writes `results.json` and `findings.json`; flags require review and are not an automatic pass/fail certification. It does not submit forms and blocks third-party requests. Local flat HTML navigation is adapted for the static preview server; live header tests must be performed separately.

Evidence captured in this environment: `/tmp/viikkonro-ui-audit/results.json`, `/tmp/viikkonro-ui-audit/confirmed.json`, `/tmp/viikkonro-ui-audit-focused/`, `/tmp/viikkonro-live-ui-audit.log`, `/tmp/viikkonro-ui-extra-widths.log`, `/tmp/viikkonro-private-ui-audit.log` and `/tmp/viikkonro-widget-ui-audit.log`. These temporary files are not permanent repository artifacts.
