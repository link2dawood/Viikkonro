# Security Policy

## Supported Versions

The project is currently maintained on the default branch.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Report them privately through the repository maintainer or the GitHub security contact for the project.

When reporting a vulnerability, include:

- a description of the issue
- affected files or routes if known
- reproduction steps or a proof of concept
- the potential impact
- any suggested remediation

We will review the report and respond as quickly as possible.

## Disclosure Expectations

Please keep vulnerability reports confidential until a fix is available. If a fix is ready, we may coordinate a public disclosure at an appropriate time.

## Scope

This policy applies to security issues in the repository, application code, dependency tree, or deployment configuration related to this project.
